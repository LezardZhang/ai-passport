## 基线与分配台账

评估镜像：`04eba2bb76e4844f928a91567fa7a126b17fb150bd64c4a60302161e904e3f10`；
ELF：`c6a870f29f9ba7f5c48b30dddb6712a7a7bf09f3300cfd1751f5bd1361908da3`；
检查点：`24ac50cca60eba2aff72aa879c939c3edcd1dc9d`。
平台：ESP-IDF 5.5.3、ESP32-C3、无 PSRAM。
配置／分配来源：[默认配置](../../sdkconfig.defaults)、
[显示 BSP](../../components/bsp/src/bsp_display_lvgl.c)、[AI 任务](../../main/xigua_ai.c)、
[应用](../../main/xigua_app.c)及[后台任务](../../main/xigua_backend.c)。
尺寸变化时必须重新核对实际构建配置。

| 资源／所有者 | 大小与证据类型 | 生命周期／释放／重叠 |
| --- | --- | --- |
| LVGL／UI | 配置值：28,672 静态池 | 应用存活期间；单独测量池内指标 |
| LCD／BSP | 配置值：19,200 单 DMA 缓冲，40 行 | 显示存活期间；所有活跃 UI 阶段都存在 |
| 目录／应用 | ELF／配置值：10,000 静态 + 10,000 刷新副本 | 静态保留；发布或失败后释放副本；刷新重叠需要仲裁 |
| 回复／应用 + AI | ELF／配置值：12,304 静态副本 + 4,104 队列负载 | 结构保留；只有一个有效模式／结果所有者；额外朗读副本也要计入 |
| 记录／育儿／撤销状态／应用 | ELF：6,912 静态字节，包含两个育儿事务备份 | 应用存活期间；额外上下文／JSON 副本需另测峰值；保留 NVS 与撤销正确性 |
| 育儿／交接文本／应用 + 后台 | ELF：7,680 静态字节 | 应用存活期间；另计 JSON／上下文构造 |
| AI／云端／LVGL 任务栈 | 配置值：6,144／6,144／7,168 | 任务存活期间；最低余量未验证 |
| TTS PCM 任务栈 | 配置值：4,096 | 仅播放期间；工作任务退出后回收 |
| TLS 内容缓冲 | 配置值：接收 16,384 + 发送 4,096 | HTTPS 存活期间；不含证书／RSA／TCP／客户端／解析分配 |
| JSON／AI + 后台 | 配置上限：Chat 16,384；ASR 4,096；后台 8,192 或目录 16,384 | 请求／响应期间；计入 JSON 树、编码负载和扩容副本 |
| 临时语音／AI | 配置值：2,097,152 Flash | 共用 `voice_tmp`；录音／TTS 归属必须互斥；不得播放未完成缓存 |
| 完整回复字体／UI | ELF：4,050,047 Flash 数据，静态 DRAM 为零 | 映射常量；绘制／缓存 RAM 单独计入 |

这些是分配组成项，不能直接相加为总量。评估中的链接时
`.data + .bss + .iram.text` 总计 206,174 字节，已经包含表中部分项目。
运行时台账仍缺 Wi-Fi／BLE、codec／I2S／DMA、JSON 和 LVGL 的实测峰值；
未知项目不得当作零。

应用 Flash 为 6,185,888／6,225,920 字节，仅余 40,032 字节。
分区：NVS `0x9000/0x6000`、PHY `0xf000/0x1000`、factory `0x10000/0x5f0000`、
`voice_tmp` `0x600000/0x200000`。镜像增长必须明确说明容量和后续更新空间方案。
缩减缓存或调整分区必须评估录音时长、朗读容量及现有数据保留。

## 必须遵守的阶段调度

除非明确释放，UI／显示以及既有系统／工作任务栈保持驻留。
下表描述必需的资源生命周期，包含准备阶段。

| 阶段 | 允许的高开销资源 | 应延后的工作／切换要求 |
| --- | --- | --- |
| 空闲 UI | 一个后台网络作业 | 同步／目录从构造到清理全程串行 |
| 麦克风录音 | 采集 codec／I2S／DMA、Flash 录音分块 | 延后同步／目录／BLE；ASR TLS 前释放音频 |
| ASR | 一个 HTTPS 客户端及有界编码／解析缓冲 | 不保留 PCM DMA；Chat 前释放请求／客户端／缓冲 |
| 问答／故事生成 | 一个 HTTPS 客户端、有界请求／回复 JSON | 不提前初始化音频；延后同步／目录／BLE；上传后释放请求，朗读前释放客户端 |
| TTS 下载 | 一个 HTTPS 客户端、SSE／ADPCM／Flash 缓存缓冲 | 不启动 PCM 任务／DMA；完整验证缓存，再关闭／释放网络后播放 |
| 缓存朗读 | codec／I2S／DMA、PCM 任务及有界解码缓冲 | 不保留 TLS；扬声器资源回收前延后重型同步／目录／BLE |
| 网络媒体 | 媒体客户端 + PCM 资源 | 必须单独验收重叠预算；当前 HTTP 不证明未来 HTTPS 可用 |
| BLE 配网 | 有界的 Wi-Fi／BLE 配网资源 | 延后 AI／音频／同步／目录；关闭后释放无线任务／处理器并测量回收 |

各阶段允许轻量状态／时钟 UI 更新，但仍计入峰值预算。延后同步必须保留用户数据。
进入阶段遇到冲突时，采用有界等待或可重试的忙碌状态；部分回复／缓存不得标为有效。

## 预留与已知差距

初始规划目标：峰值保留 **20 KiB 内部可逐字节访问堆**，适用能力的连续块比
**下一次最大分配至少多 2 KiB**。这是针对并发驱动／UI 活动和碎片的暂定工程余量，
不是实测需求或容量充足的证明。后续分配还要另行计入。不得为了让失败采样变成通过
而降低目标；修改目标必须提供最坏负载的实机证据。
DMA 预留、LVGL／任务栈余量仍为 **UNVERIFIED**，整体验收前必须根据真实
驱动／内存池／栈峰值确定数值。

| 证据 | 可用字节 | 最大连续块 | 含义 |
| --- | --- | --- | --- |
| 当前镜像自检前 | 63,404 | 51,200 | 阶段采样，不代表峰值 |
| 当前镜像自检 TLS 建连后 | 17,952 | 7,680 | 低于规划预留；原日志使用 `MALLOC_CAP_8BIT`，不是新的能力分类跟踪 |
| 上一镜像 `c2c6e764c004...` 真实问答 TLS 建连后 | 13,020 | 7,680 | 仅作旧版本比较；DMA 可用 5,264 |

Chat 的 16 KiB 正文上限必须计入 TLS 存活时的完整分配／扩容预算；
7,680 字节最大块不能证明该上限可达。已知缺口：云端快照和目录副本在联网锁前分配；
媒体不受该锁覆盖；BLE 活跃峰值／回收未知；没有连续最大块跟踪或完整阶段最低堆证据。
当前先缓存再播放的 TTS 已通过主机生命周期测试；新镜像实际故事发声和连续负载
内存验收仍未验证。

## 回收顺序与验收

先用阶段仲裁覆盖准备至清理全过程，并补齐测量，再评估显示缓冲、精简目录引用和
回复所有权。评估预计可回收 20–24 KiB RAM，属于尚未实施的估算，伴随 UI／后台／
所有权取舍。保留录音、统计一致性、问答和故事。盲目缩小 TLS 或移除 Flash 字体
不属于已验收的 RAM 修复。

验收记录必须包含匹配镜像／配置和框架指标，覆盖最大录音／回复／列表；
问答 → 故事 → 问答；朗读／暂停／继续／重播；取消和重试；Wi-Fi 恢复；
配网开关；延后同步恢复。初始压力负载为预热后至少连续完成 20 轮麦克风 → ASR → 问答／故事流程和
10 轮配网开启／关闭。这是最低回归负载，不是可靠性保证。
要求相同空闲状态内存稳定、满足文档预留、无分配失败、模式正确、实际发声，
并保持记录／统计完整。

运行时准入检查、完整阶段仲裁、指标采集和 DMA／LVGL／栈数值预留仍需实现。
文档检查和固件构建成功不能消除这些缺口。
