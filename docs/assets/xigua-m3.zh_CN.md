# 西瓜 M3 本地声音增量

本阶段在[联网与记录阶段](xigua-m2.zh_CN.md)之上加入三种合成环境声音、本次开机音量和计时提醒仲裁。这是实现检查点，不代表设备验收。原 M3 已刷入并通过 USB 状态查询；用户反馈声音小、三种音色相似，本次修订处理已定位的软件原因。修订版实机验收仍待进行。

## 操作

首页声音卡按 OK 进入声音页。上下选择白噪声、雨声或海浪，选择本身不播放。OK 播放选中的声音；对当前请求播放的声音再按 OK 则暂停。长按 OK 进入音量页，上下每次调整 5 个百分点，OK 返回。长按下返回上一页；离开声音页或屏幕变暗不会停止播放。长按上保留快速记奶入口。

音量范围 0–100，默认 40。原上限 40 在 codec 上仍对应约 -30 dB 衰减，导致界面最大值的输出仍很小；现在可使用完整 codec 范围。这是软件设置，不是实测声压值。音量和选轨仅本次开机有效；重启恢复暂停和默认音量，不会开机自动播放背景声。三个名称描述合成音色，不是环境录音或经过临床评估的声音产品。

## 生成与资源归属

[xigua_sound.c](../../main/xigua/xigua_sound.c)按 16 kHz、16 bit、单声道生成 PCM。白噪声使用确定性伪随机序列；雨声叠加滤波底噪与不规则共振雨滴；海浪混合低沉水声与中频浪花，并有明显的八秒起伏。提醒音是一秒内三段带包络的渐升音。生成器状态为 36 字节、无堆分配，输出音量控制前的采样幅度限制为 24,000。不加载完整音频文件，不需要新增音频分区或外部素材许可。

一个应用 worker 独占 BSP codec/I2S 调用，每块生成 320 个采样（640 字节、20 ms），任务栈 4 KiB。首次播放或计时提醒时才初始化 codec。按键只更新有界的目标状态并通知 worker；LVGL 读取复制的状态，音频不持有页面对象，切页不影响播放服务。

暂停/停止在当前操作结束后调用 BSP 休眠。BSP 休眠释放 codec 对象，但保留 I2S 通道和 DMA 分配；worker 持续存在。这些是有界保留资源，不代表整个音频子系统完全释放。codec 失败会显示，用户可明确按播放重试，不自动循环重试背景声。

## 计时与故障行为

本地计时首次到期请求一次有限提醒。提醒暂时打断环境声，结束后按最新请求的背景播放状态继续。提醒期间暂停会同时取消提醒和背景续播。清除或重新设置计时会取消提醒；撤销无关记录不会让已到期的计时重新响起。音量为零时音频静音，屏幕仍显示计时提示。

请求合并为最新目标状态，停止不会因为命令队列已满而丢失。generation/alert 标识防止旧完成通知消耗新提醒或覆盖新意图。底层 codec 写入使用依赖中的 1,000 ms 等待超时，因此停止不是瞬时取消保证，codec 休眠与任务调度还会增加延迟。启动/恢复使用淡入，切换是否无爆音仍需上板试听。

CONFIG_I2S_ISR_IRAM_SAFE=y 使 DMA 中断能在 Flash 写入期间继续响应，但不能保证 Flash 中的生成任务持续运行，也不证明播放无卡顿。NVS 布局、事件 Schema 和记录容量均未改变；TLS 与音频并行时的堆余量仍需测量。

## 诊断与验收

现有 USB status 命令新增音频是否可用、播放/提醒状态、所选轨道、请求音量、最近错误、最大观测供数间隔和音频任务栈最小余量。播放前栈采样值为零不代表已测得余量。供数间隔只是软件计时，不等于声音卡顿检测；同一回复仍提供堆内存计数。

主机检查覆盖确定性和分块无关的合成、幅度上限、无效输入、提醒结束、连续音色统计、海浪周期边界和播放仲裁；固定 UI 字形另行检查。这些检查无法确认 ES8311 输出、实际音色、扬声器声压或硬件时序。

实机仍需至少连续播放 20 分钟并同时翻页、保存记录和运行计时；反复播放/暂停/切轨；提醒中停止；静音；codec 失败/重试；采样率/音调正确；无持续分配增长；以及网络工作时的堆与栈观测。ASR、TTS、PTT、夜间模式和云音频留待后续；A 版完整验收还需要 M0–M2 的实机检查及持续网络/音频并发检查。


## 设备端 Wi-Fi 配置

进入“更多 → 设置”，按 OK 打开 Wi-Fi。扫描最多列出八个可见网络，可选择网络或手动输入 SSID。编辑名称/密码后，选择“保存并连接”。明确保存时更新同名配置或使用空槽；八个配置已满时需通过 USB 管理。记录存储和 AI Key 不变。配置保存成功与取得 IP 地址分别显示。

5×5 软键盘使用四行字符键，最下一行固定为“小写、大写、数字符号、退格、确认”。上下键选择前后单元格，OK 激活；长按 OK 在当前字符集内换页，长按下取消且不占用可见按键。每个字符集末尾的 SPC 输入空格。覆盖全部可打印 ASCII，包括大小写字母和密码标点。手动网络名称最多 32 字节；密码可留空用于开放网络，或使用 8–63 个字符、64 位十六进制值。密码始终掩码显示。退出编辑页清除其密码副本；取消键盘编辑保留此前接受的字段。配网期间不会触发记录快捷键。

扫描取得的 UTF-8 网络名称保留原字节用于连接；固定 UI 字库不覆盖任意网络名，非 ASCII 字节明确显示为十六进制转义。扫描、保存和连接在后台任务执行；网络失败后可修改并明确重试。固件未编译 Wi-Fi 密码或 API Key。
