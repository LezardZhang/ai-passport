连接其他 Wi-Fi
支持 2.4 GHz 网络。也可手动填写隐藏网络名称。
Wi-Fi 密码仅通过配对后的蓝牙发给设备，不上传云端。设备拿到 IP 后保存；连接失败不会覆盖原来保存的网络。
