# Android 第五版分配与阶段预算

本预算与ESP32-C3固件独立，APK大小或编译通过不能证明运行储备；Android录音器、解码器和TTS会在Java堆之外分配。

| 所有者 | 准备到清理 |
| --- | --- |
| 主线程/UI | 记录/音频/提醒/冲突各最多100行，统计流式SQLite；输入/回应12,000字、备注2,000字，语音刷新保留输入区。 |
| 数据库线程 | 串行写入/导入/生成，事务保留记录及队列；不淘汰历史/队列。 |
| 网络线程 | 同步/对话/模型/更新单任务；JSON回应1MiB，连接10秒，Personal API读取30秒、提供方60秒。JSON解析/字符串复制规划约8MiB瞬时范围，另加配置。 |
| 服务配置 | 最多20套，每套512个模型ID、每ID200字；序列化元数据2,097,152字符（UTF-16约4MiB、UTF-8最多约6MiB）。编辑/列表/快照可共存，需要覆盖这些序列化副本的额外储备；内置配置读取128KiB上限。 |
| 语音线程 | 一个录音器或识别传输，16kHz单声道16位PCM、4KiB缓冲，无固定录音时长截止。载荷64MiB、磁盘储备4MiB、开始前检查8MiB；识别前释放录音器；草稿保留到成功/取消。 |
| ASR暂存 | 原草稿加一个60秒传输WAV段（1,920,044字节），8KiB流式编码，单段线上约2.56MiB，不构造整段数组。回应1MiB/12,000字，合并文字12,000字。取消断开并拒绝回调、清理未完成录音/分段。 |
| 媒体/TTS | 单播放器/会话，平台流式解码；合成后检查单文件128MiB上限，文字每段3,500字。停止/失败释放焦点及TTS，暂停5分钟释放；系统峰值仍未测量。 |
| 更新暂存 | 清单64KiB、APK64MiB、32KiB缓冲；旧64MiB加新临时64MiB可共存，初始4MiB检查、复制2MiB储备，校验后交给安装器。 |

语音和网络最多两个应用HTTP并发，另加平台播放/UI/数据库。同步每次最多100次提交及100页×100条；持久历史分页。直接请求的提供方快照仅为未完成任务保留，终态/冷启动恢复会清理。排队请求及历史仍会增长，由用户导出/管理。

音频导入32KiB缓冲，每项128MiB、目录256MiB含临时文件；冷启动清理中断文件。30秒离线雨声2,646,044字节。旧64MiB录音草稿+新64MiB录音+1.83MiB识别段规划约130MiB；导入256MiB、TTS128MiB、更新128MiB加语音130MiB共约642MiB，另需数据库/日志/导出/系统合成和安装空间。上限不代表可用空间保证。语音完成替换草稿，临时文件必须清理，完整识别失败音频有意保留。

## 证据与限制

第三版Android测试（本地产物：`../reports/android-tests-v3.log`）用真实AudioRecord验证发送/重复/失败/重试/退后台及跨刷新65秒录音。真实接口测试（本地产物：`../reports/android-live-provider-v3.log`）用生成中文语音验证模型、对话及ASR，不代表人声准确率或麦克风音质。UI证据（本地产物：`../reports/native-ui-smoke-v3.json`）及PSS采样（本地产物：`../reports/memory-sample-v3.txt`）为模拟器单点，不是峰值/无泄漏证明。历史第二版稳态32,526KiB、0.1真机115,196KiB不能代表第三版。

真机规划目标仍为稳态PSS≤128MiB、瞬时≤160MiB并稳定清理；最低设备/API26、长后台/来电/耳机/重启/TalkBack、低磁盘、最大回复/配置/导入、并发同步及原生连续分配储备仍待验证，不把编译或单次采样写成容量保证。

## 时间线扩展

配置：安卓每页100条，各含时间文字、装饰竖线和记录卡片，页面重绘释放。照护者表单最多100个活动人物加两个原快照/未知选项，姓名40字、ID128字。原生保真发送复制一份有限长度远端 JSON 到一个请求，沿用1MiB请求/响应上限。网页每页100卡片、最多100姓名建议；继续加载会保留累积页，历史越多 DOM 越大，不声称峰值容量。服务查询仍先读完整快照再筛选排序，需要 O(n) 存储和 O(n log n) 排序。大历史量与生产 RSS 未验收。未增加媒体、字体或依赖，也未改 ESP32 固件。

## 云端发布扩展

自动检查最多排队一次，6小时节流限制反复启动；更新和服务调用/同步共享串行网络执行器。清单64KiB及有限JSON副本、APK64MiB和32KiB缓冲沿用前述暂存预算。服务哈希使用64KiB缓冲；ZIP预检最多读取65,557字节，只允许≤2MiB中央目录/4096对象后解析。一个上传可与带鉴权下载并存，OS/FastAPI/套接字和FileResponse仍有平台开销。容器192MiB、磁盘128MiB储备及2GiB历史发布配额是配置，不证明峰值RSS、并发容量或可用磁盘；生产容量和最低手机更新储备仍未测量。

首次发布后生产容器一次抽样为32.77MiB/192MiB，2个进程；该点位抽样不代表峰值RSS或并发/负载验收。
