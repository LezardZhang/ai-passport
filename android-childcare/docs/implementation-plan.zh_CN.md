# Android 育儿实施计划

**目标：** 可安装原生应用及可审阅设计。
**架构：** SQLite 唯一界面数据源、持久操作队列、按实际契约接入；原生语音和前台媒体播放。
**规格：** [架构](architecture.zh_CN.md)、[UI 规范](../design/design-spec.zh_CN.md)。
**执行：** 本会话实施，已委派设计代理独占 design/。用户已授权改造，不重复询问方向或批准，不切共享分支、不提交。

## 全局约束
- 只写 android-childcare/，维护文档中英成对。
- 包名 cn.xigua.childcare，最低 API 26，目标 API 35，独立本地开发签名。
- 媒体和 JSON 有上限；主线程不联网；不伪称线上接口可用。

## 审查重点
- 午夜/DST 睡眠按所选本地日的重叠时间计算。
- 离线删除/重试保持操作身份和墓碑。
- 服务端清空/冲突不能让旧记录复活或覆盖。
- 后台/取消释放麦克风，AI 不串模式。
- 进程死亡/焦点变化重建持久状态、不自动播音、停止即释放。

## 任务
1. [x] 主机失败测试：CareRules 日期范围、校验、CSV 安全、RequestOwner；实现纯 Java 规则并测试。

3. [x] 按设计规范实现四个原生主入口和编辑弹窗；页面读取同一 Store，重建保留草稿和日期。

5. [x] 前台播放、焦点、通知、流播放/本地库、有界导入和定时停止；检查实际 UI/设备。
