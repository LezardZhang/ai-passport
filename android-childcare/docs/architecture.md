# Android architecture v4

[Design](phone-v3-design.md) and [plan](phone-v3-plan.md). Native Care/Records/Family use one retained CareComposer. Host-tested IntentRouter/CareRules create structured confirmation candidates, not automatic record writes.

SpeechSession owns phase/generation/pending Send. VoiceInput validates frozen provider configuration before capture, owns permission/foreground cancellation and ignores old callbacks. MicrophoneCapture streams AudioRecord PCM, releases the recorder before network work, and retains a completed failed WAV in SpeechDrafts. SpeechAudio writes bounded sequential WAV segments. One speech executor prevents overlapping microphones/ASR calls; completed drafts survive background interruption, explicit discard removes them.

Providers persists named profiles and independent chat/ASR bindings in schema3 metadata. Revisions fence asynchronous discovery against edits/deletion; GET /models IDs cache separately. Each request stores a provider snapshot and transport ownership. AiEngine runs direct requests; backup Api cannot claim a direct request or replace its chosen provider. Legacy server jobs retain their server ownership. Interrupted direct generation is a visible retry.

Store schema3 keeps people lifecycle, historical name snapshots, event/outbox UUIDs, requests, reminders and media. Populated schema2 migration preserves data/operation IDs. New backup protocol context stores service UUID/profile UUID/Base URL when an intent/editor is created. Existing-row edit/delete/sleep completion inherits original context. Api discovers capabilities without prior header, then contextual reads/mutations use captured identity. Old missing/replaced identity is quarantined, never automatically rebound. Cursor pages apply transactionally; local pending writes survive pull, reset generations cannot resurrect records. Local family contacts remain local. A bounded caregiver ID/name snapshot now synchronizes in `data.caregiver` when capabilities declare `childcare_caregiver`. Unsupported services keep named operations pending. Old frozen requests replay unchanged, then an atomic acknowledgement queues a separate attribution repair if needed. Explicit-null remote attribution clears the name; omitted legacy fields retain the local snapshot. Explicit keep-local conflict recovery retains the local actor, including a deliberate clear.

One database executor serializes writes, one network executor serializes sync/chat/models/update operations. The independent speech executor allows at most two app HTTP calls. Native playback/TTS share one foreground player/session. Updates stream bounded files, verify SHA256/package/higher-version/OS/exact signer and expose readonly staged files with URI grants; Android confirms installation. No real backup token or release channel was supplied. [Resource budget](resource-budget.md) and [delivery](delivery.md) distinguish measured evidence from planned limits.

[Timeline architecture and acceptance](caregiver-timeline.md): native continuous rail,100 rows/page, explicit caregiver picker and retained rotation draft; management text-only cards, daily snapshot paging and simple activity form. Nullable/custom data and independently supplied sleep duration remain intact when attribution alone changes.
