# 照护者时间线实施计划

目标：安卓与管理后端按天显示竖向时间轴，每条包含实际照护者、发生时间、动作，以及奶量、尿布类型等详情。

架构：沿用 SQLite、待同步队列和服务/档案身份保护。增加可选 `data.caregiver`，包含稳定不透明 `id` 和有限长度的姓名快照 `name`；显式 null 表示未知。旧客户端编辑时省略此字段，保留已有快照。家庭联系方式留在本机，记录归属随记录同步。管理端可逐条填写照护者，已有快照提供建议；这不是账号认证或跨设备通讯录。

展示：按真实时间升序，时间相同用记录 ID 稳定排序；未知时间置于末尾独立标注。按天筛选包含跨日睡眠及明确标注的无日期记录。时间列与连续竖线连接记录卡片。历史归属不推测为当前账号或当前照护者。

全局约束：保留其他后端改动、旧 APK、私有配置和签名。不发布、不推送、不清空数据、不修改固件。既有授权允许同签名安卓升级。使用 executing-plans 在当前会话执行、先写有效测试、最终做一次独立审查。安卓与后端为未跟踪并发工作，沿用当前目录，不额外提交，也不重复要求确认本次继续任务的设计。
