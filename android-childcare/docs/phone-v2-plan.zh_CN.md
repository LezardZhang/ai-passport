# 手机第二版实施计划

> **供执行代理：** 使用superpowers:executing-plans在当前会话实施；UI设计子代理仅负责design/。

**目标：** 在现有Android应用交付简化照护入口，以及持久的人物和版本维护流程。
**架构：** 原生界面、独立意图和校验规则、SQLite版本3、限额MiMo传输和Android安装器；保留现有同步及媒体生命周期。
**技术：** Java8源代码、Android API26–35、SQLite、HttpURLConnection、AudioRecord。
**设计：** [第二版设计](phone-v2-design.zh_CN.md)。

## 约束及评审重点
保留记录、待同步身份与签名。后端/固件只读。本机人物不授予云端权限。提问中出现照护关键词不代表写入。取消后拒绝迟到转写和回复。不接受其他包名/签名或旧版本更新。照护者编辑/停用不能改写历史归属。
