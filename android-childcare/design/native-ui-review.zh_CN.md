# 原生实现 UI 交接审阅

第二版导航更新：[三个主入口的精简设计](simplified-design.zh_CN.md)已有提供的原生照护/记录/家庭截图。下方第二版段落审阅此实现；较早的四入口发现与截图仅保留为历史证据。

首轮源码审阅：2026-10-02；最终模拟器截图审阅：2026-10-03，Asia/Shanghai。下方首轮发现针对较早的 `MainActivity.java`/`Ui.java`，作为历史记录保留；最终截图段落取代其中对可见状态的旧判断。本审阅不修改应用代码，也不证明真实手机、麦克风或音质验收通过。

首轮实现已经遵循四个主入口，使用原生控件，明确本地/生产尚未验证状态，并从空时间线开始。当时提出以下建议：

| 优先级 | 发现 | 具体调整 |
| --- | --- | --- |
| 1 | 今日有喂奶/睡眠/尿布，但没有快捷语音记录；语音仅在问答/故事中。 | 三入口后增加“说一句，就能记”。识别先变可编辑文字，再展示类型/时间/数量预览；确认保存才写记录。未知/含糊指令保留文字供修改。 |
| 2 | 睡眠主区域采用和辅助卡片相同的浅绿，活动状态视觉重点弱。 | 进行中用深松绿 `#214E43` 与浅色字，44–48 sp 独立时长、浅色结束按钮；无活动睡眠保留较轻的空状态。 |
| 3 | 三等分的快捷入口/统计/日期和四等分音频类别假定紧凑文字。 | `fontScale >= 1.3` 时改纵向或自适应换行；日期前后操作可用图标加完整无障碍标签。200% 下保留完整数量/时长意义及全部操作，不能横向截断。 |
| 4 | 播放条是标题加三个 52 dp 按钮，可能在导航前占用超过 100 dp。 | 改标题 + 暂停/继续 + 停止的紧凑 64–80 dp 行，把定时/跳转移到完整播放器/详情；标题视觉最多两行，完整名称无障碍可读。准备中和不可恢复错误显示实际准备/重试语义，不能一律给“继续”。 |
| 5 | 日间辅助色 `#718078` 在奶油底上太淡；换页继续保留旧页滚动位置。 | 辅助色改为 `#667267`（对 `#FAF8F3` 为 4.75:1）。新入口先回顶部，只在同页数据更新时保留滚动位置。 |

其他边界：必须实现的导出是 CSV，设计中的 JSON 为未实现前的可选能力。亲喂时长/侧别、最近删除恢复、提醒延后/编辑、多时间范围和语音结构化记录，不工作时不能显示已经完成。交接备注当前仅本机保存，在实际后端契约支持前继续明确标识。设计文案不能覆盖应用准确的能力状态。

完整状态、导航、无障碍与文案见[设计规格](design-spec.zh_CN.md)。夜间/大字截图（本地产物：`screenshots/night-large-type.jpg`）展示自适应纵排；喂奶表单（本地产物：`screenshots/feeding-sheet.jpg`）与录音（本地产物：`screenshots/voice-recording.jpg`）展示操作层级。原型演示界面状态，不证明手机录音或音质。

本版接受的实现差异：原生人物表单直接提供可编辑预览；当前照护者需要先切换再停用，而非隐式清空。主流程报告已支持登记/编辑/切换/停用/恢复，失败保留草稿；这些行为没有仅靠静态截图推断。

提供的 Android 仪器测试记录（本地产物：`../reports/android-tests-v2.log`）报告 98 项断言通过，包括实际前台 AudioRecord 捕获、Home 取消/临时 WAV 清理、人物生命周期和升级身份检查。这是独立执行证据，不能证明音质、识别准确性、线上升级频道或正常在线模型已经可用。正常 MiMo API 仍需单独配置凭据，Google 未启用。原生升级实现支持可选 HTTPS 清单、64 MiB 上限 APK 导入、同包名/签名及更高版本检查，最后由 Android 系统确认；在线频道尚未部署。云账号注册/邀请仍不支持。

证据边界：本审阅没有直接操作原生 UI 或自行执行仪器测试。完整 TalkBack/焦点语义、键盘弹出可达性、人物/更新/播放/弹窗 200% 布局、权限恢复及第二版真机行为尚未由这些图片验证。资料失败/草稿恢复、频道错误/下载取消和安装结果需要对应功能证据。HTML 原型语音/AI/媒体/更新/恢复仍为设计演示，浏览器人物持久化独立于 Android 数据层。可选设计能力只在有各自实现与验收证据时才可宣称完成。
