# 简化育儿导航与家庭长期管理

第 2 版，2026-10-03，Asia/Shanghai。用户要求手机菜单更少、语音/大模型合为一个入口并按意图分流，补齐人物登记/管理/更新与长期运作。本版取代第 1 版的四个主入口，只修改设计产物，不代表 APK 或后端已经实施。

待用户核对的解释：人物指默认宝宝与家庭照护者；维护包括 App 版本身份及升级。本地人物登记不等于云账号注册。没有实际后端支持时，不宣称云账号、家庭邀请、权限委派和在线升级可用。

## 三个入口

| 入口 | 用户目的 | 内容 |
| --- | --- | --- |
| 照护 | 说出/输入需要做什么 | 统一对话、当前宝宝/记录人、活动睡眠、意图/结果卡、录音与播放状态 |
| 记录 | 查事实、改记录 | 日期/范围、同源统计、时间线、编辑/删除/恢复、导出 |
| 家庭 | 维护人物与应用 | 宝宝资料、照护者登记/切换、资料更新/停用、服务状态、版本/备份/空间 |

问答、故事、音频库、提醒、交接不再占独立主菜单，而是照护中的意图与结果。对应任务可打开专用编辑、声音选择和媒体详情。打字和语音共用路由，建议短句只填输入框，不自动执行。返回先关表单，再回主入口；换入口回顶部，同一对话刷新保留有用位置。

## 统一输入与意图分流

输入提示“记一件事，或说说你需要什么”。语音有准备、权限、捕获、识别、可编辑文字、取消、中断、失败状态。填入识别文字不发送。拒绝权限/识别不可用时仍可用系统输入法。后台释放捕获，保留已有文字，不能声称丢失原音频已恢复。

| 意图 | 去向 | 确认与离线行为 |
| --- | --- | --- |
| 喂奶/尿布/洗澡/趴趴 | 结构化记录预览 | 展示宝宝、记录人、量/类型、发生时间，确认才持久写入；离线队列 |
| 开始/结束/补记睡眠 | 持久睡眠状态/区间预览 | 确认修改，切页/进程回收保留；无活动睡眠时说明 |
| 今日查询/交接 | 本机查询结果卡 | 明确本机/确认口径、时区、新鲜度；联网增强可选 |
| 普通问题 | 有归属的问答任务 | 展示文本及使用的记录上下文，再按真实能力提交；服务不可用保留草稿 |
| 故事 | 有归属的故事任务 | 共用入口，任务/结果/媒体身份独立，文字与朗读可各自失败 |
| 播放/停止/暂停 | 一个原生播放器 | 选择真实本机项或服务支持目录；录音协调音频焦点 |
| 提醒 | 标题/时间确认表单 | 本机持久保存，权限/调度状态明确 |
| 登记/更新人物 | 显式资料表单及改动预览 | 模型不能直接改资料；本地事务、身份版本保留 |
| 模糊/多个意图 | 澄清卡 | 询问动作与目标，保留文字，不产生副作用 |

含糊请求不能静默变成普通回答、猜测人物或任意记录。写入、删除、导入先预览目标与变更，取消不写入；普通信息结果无需重复批准即可阅读。路由可用已测试的本地确定性指令，和按能力启用的模型解释；界面不能承诺不存在的分类端点。

每个对话项有稳定请求 ID、意图、宝宝/记录人、原输入、状态、结果、媒体归属。合并入口不等于共用一个可变“最后回复”。问答和故事保持独立类型任务。迟到结果只更新原卡；切宝宝/人物/页面不重新归属旧任务。取消使回调失效，重试遵守真实后端幂等。联网前持久保存提交状态，进程恢复后可恢复中断任务，不自动播放。

结果卡如实显示待确认、保存中、已存本机/待同步、处理中、取消、中断、可重试失败、冲突或服务不可用。原型中的 AI/媒体标为界面演示；产品必须显示实际能力和状态，不使用演示回复冒充服务。

## 本地人物登记与管理

首次启动保留现有默认宝宝 ID，仅有昵称；不虚构生日、照护者、年龄，不要求登录才记录。记录人未知是真实未设置值，不捏造家人，可之后再登记。

登记路径：家庭 → 登记照护者 → 必填姓名/称呼和关系，可选备注 → 核对“本机人物，不是账号” → 本机保存 → 设为当前记录人。空姓名、存储失败保留草稿，说明原因并能重试；本地事务成功才提示已保存。原型人物存在演示浏览器，不修改 Android 数据库或云端。

详情展示当前记录人、本机/云支持状态与资料版本。更新保留同一人物 ID，预览改动并增加修订。切换只影响新记录署名，不改变宝宝归属或旧历史。停用先确认，不再供新记录选择，但保留历史人物引用，停用当前人物时清空当前记录人。实现恢复时复用原身份；停用不能冒充撤销云账号权限。

宝宝更新保留默认宝宝 ID 和记录关联。昵称必填、生日可空且不能是未来、备注可选。改生日只影响年龄展示，不改历史时间。时区变更解释每天统计边界。多个宝宝/家庭不在已确认第一期范围，除非用户改变要求。

实现把人物、修订/停用、记录人引用和持久操作队列纳入同一事务本地数据层。有真实契约才启用资料同步，否则标“仅本机”；不能把没有同步的字段静默展示成云端完成。以后账号/邀请流程必须另有身份、授权、撤销、恢复契约。

## 长期运作与版本维护

家庭 → 版本与维护分组展示实际安装包名/版本/签名渠道、更新来源、上次成功检查、空间/缓存、备份/导出、恢复。安装身份从系统包管理器读取。“更新渠道未配置”不等于“已经最新版”；检查失败保留上次版本与信息时间。未配置/不可用端点不提供假检查成功。

实际支持升级时：核对清单/版本/包名与签名，分块下载且可取消重试，校验大小/哈希/签名，再交给 Android 系统安装。必要系统授权由用户完成，不能静默安装。未有可信渠道前解释可靠本地 APK 安装，先提供备份。保持独立育儿包名和稳定签名，不借用成人应用身份。

本机长期流程：人物/记录/队列事务持久化，恢复活动睡眠和草稿，协调未完成任务，有界同步/提醒，暴露空间失败。清缓存不删除照护与人物历史。历史/对话分页，音频/网络缓存有界，不把整个大文件堆内存。离线不需要永久服务连接。

升级采用版本化事务迁移，迁移前备份并能回退。失败保留旧数据库/队列并提供恢复，不能默默重置。备份预览显示人物/记录数、schema/版本、时区、待同步和排除项（不含凭据）。恢复先校验完整性，预览合并/替换/冲突，确认后写入；尊重服务器清空代次，旧备份不能复活已清空数据。未实现恢复时如实说明，不展示已恢复完成。

运行状态包括上次成功同步/备份/检查、待同步/冲突数、中断任务、通知权限、可用空间。用简洁分组并在可处理时开详情，不为每个状态新加技术菜单，不承诺永久后台。

## 视觉与实现交接

保留奶油/松绿/杏桃与 48 dp 点击区，底部为照护/记录/家庭。对话输入是主操作，固定在底部导航上方，对话内容独立滚动，语音与发送始终可达；紧凑宝宝/睡眠状态提供上下文。人物和维护用分组列表。大字可换行、纵排、滚动表单；原生输入法/日期时间，TalkBack 描述意图、记录人、目标和状态。

查看 [prototype.html](prototype.html)。第 1 版截图和原生审阅是历史证据，不能宣称 APK 已改成第 2 版。原型人物实际只保存演示浏览器资料；AI、捕获、播放、通知、同步/升级/恢复仍为模拟或明确未支持交接。实施验收覆盖模糊意图、确认/取消、重复写、请求归属、人物保存失败重试、停用/历史、进程回收、升级恢复与真实手机权限/媒体。
