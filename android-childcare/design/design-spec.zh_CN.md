# 西瓜育儿：温暖照护手机设计

当前 Android 手机行为和服务档案见[第三版手机设计](android-phone-design.zh_CN.md)。录音/发送归属与无固定录音时长限制取代较早交互示例。


当前导航以 2026-10-03 的[第 2 版简化设计](simplified-design.zh_CN.md)为准。下方能力细则继续适用，问答、故事、播放、提醒、交接改由统一照护对话分流。原四入口页面表和截图是第 1 版记录，不是当前目标。

日期：2026-10-02，Asia/Shanghai。范围：原生 Android 育儿应用，一个家庭、一名宝宝。本文件是[应用架构](../docs/architecture.zh_CN.md)的视觉与交互交接规格。所有设计文件留在本目录，不修改固件、BSP 和后端。

## 产物与设计意图

直接打开 [prototype.html](prototype.html)，或在本目录启动静态服务后打开 `http://127.0.0.1:8096/prototype.html`。原型由 HTML/CSS/JavaScript 编写，设计尺寸 390 × 844，支持手机宽度。它是可审阅设计产物，Android APK 不依赖 WebView。

[design-tokens.json](design-tokens.json)包含颜色、留白、圆角、字号、组件尺寸和已约定的资源边界。screenshots（本地产物：`screenshots/`）是实际浏览器截图。[prototype.js](prototype.js)采用示例记录，并模拟语音、AI 与播放状态；它不会调用麦克风、后端、通知或播放器。侧栏明确说明此边界。开关可以演示空档案、夜间、大字、离线、麦克风拒绝和请求失败。

界面帮助抱着宝宝的家长迅速回答三个问题：现在正在发生什么，最近做过什么，接下来要留意什么。奶油底色、深松绿和克制的杏桃、淡紫构成安静且适合成人的视觉语言。清楚的数字与留白承担视觉重点，不需要装饰插画。手机界面重新设计，没有板级测试菜单、固件软键盘或等比放大的硬件画面。

APK 首次启动只创建默认宝宝身份与昵称。显示零记录、无进行中睡眠、空提醒，不虚构生日、年龄、交接留言或 AI 会话。生日未知时显示“生日未填写”。原型示例生日和历史仅用于设计审阅。

## 导航与信息结构

| 主入口 | 内容 | 二级页面 |
| --- | --- | --- |
| 今日 | 当前睡眠、快捷喂奶/睡眠/尿布、语音记录、今日摘要、交接入口 | 睡眠、照护交接、提醒 |
| 记录 | 日期/范围、临时统计、有界时间线、筛选、新增 | 记录详情/编辑、其他照护、导出、最近删除恢复 |
| 陪伴 | 三个任务明确的选择 | 语音问答、讲故事、音频库、播放器 |
| 我的 | 默认宝宝资料、服务/同步、权限、外观、存储、导出 | 档案、同步队列/冲突、服务连接、缓存、可选设备 |

日常使用中四个主入口保持稳定。Android 返回先关闭表单，再从二级页回到所属主入口，最后遵守根页面的正常返回行为。切换主入口不会结束睡眠或播放，也不删除草稿。完整播放器与持续可见的迷你播放条共用一个播放状态；播放条位于底部导航上方，不遮盖导航和最后一行内容。

交接和提醒靠近每天的家庭照护，不藏在技术设置里。设备配套功能放在可选设备设置。手机网络替代固件 Wi-Fi 配置，不保留板级测试。

## 页面与流程规格

### 今日

页头显示问候、当地日期、昵称和已知年龄、宝宝资料按钮。同步标签打开队列，分别显示“已保存到手机 / N 项待同步”“离线，记录仍可保存”“正在同步”“更新于……”“未连接”。手机联网不等于后端可用。

进行中的睡眠优先放在深松绿主区域，显示经过时长、开始日期/时间和“宝宝醒了”主操作。结束时简短确认后保存一段区间。没有进行中睡眠时邀请开始计时，并说明离开页面也会继续。空状态使用“每一小步，都值得轻轻记下”，不模拟过去事件。

三个相等的快捷入口打开喂奶、睡眠和尿布。下一行是“说一句，就能记”与示例短句。语音记录必须先展示结构化预览，再确认保存。摘要显示瓶喂量、已完成睡眠和尿布事件数；进行中睡眠单列。未知奶量不当作零；同一尿布事件同时有尿/便时，类别数不能相加冒充换尿布次数。

交接用简洁支持行呈现；存在提醒时再列出即将到来的提醒。内容可滚动，重要记录入口靠近顶部，底部导航保持可达，不通过缩小字号硬塞整天信息。

### 喂奶与其他照护

喂奶用底部表单：奶量、±10 ml、近期安全预设、喂养方式、发生日期时间、可选备注、保存。数值使用系统数字键盘，备注使用已安装的系统输入法。支持亲喂时使用时长/侧别，不虚构瓶喂量；未实现的模式先不展示。上次用量只提供输入便利，不自动创建记录。

保存走“编辑 → 保存中 → 已保存”，同步另有状态。只有本地事务完成才显示“已保存到手机”。失败保留输入并提供重试。成功提示提供七秒撤销，之后仍可从历史编辑。撤销绑定准确事件身份，以补偿操作实现，不能撤销另一条记录。

日期时间使用原生控件并说明当地时区。补记是正式能力。无效/未来时间和无效数量显示字段错误，不静默截断。异常历史值可保留供人工核对。洗澡和趴趴练习沿用表单结构，只展示对应字段；计时器是独立时长工具，不是硬件测试。

### 尿布

选择尿尿、便便或都有（仅在数据模型支持时），发生时间与可选备注。颜色、性状作为可选描述。一键保存一条事件；“都有”分别增加类别标记，不把事件数翻倍。备注次要，不妨碍快速记录。

### 睡眠

专属页面显示大计时与开始日期时间。开始立即持久保存。离开页面、锁屏、转后台或进程回收都不会生成已结束事件。进程恢复后用持久开始时间重建时长，不恢复猜测的单调时钟原点。手机时钟异常变化时显示需要核对时间。

结束保存准确起止与计算时长；独立补记表单支持跨午夜。按契约检查结束晚于开始、未来时间与重叠。已完成行展示区间，而非仅时长。当地日期统计取时间区间与请求范围的交集。活动睡眠单独显示，不混入已确认的完成睡眠。

睡前音频是同一音频库和播放器的辅助入口。睡眠计时与音频定时停止是不同状态。

### 记录、历史与统计

提供今天、近七天、本月、日期切换和明确范围。筛选全部、喂奶、睡眠、尿布，其他类别仍可发现。每行显示发生时间、类型/数量、相关详情和同步状态。点击进入详情编辑/删除。删除创建墓碑并提供立即恢复；实现最近删除后，提示超时仍能恢复。

界面观察同一个持久本地数据源；列表与统计从同一次已提交状态更新。持久保存前不抢先改计数。可见行最多 100，分页读取旧记录，不能为了显示上限丢弃历史。

统计键包括宝宝身份、数据修订、时区、半开时间范围。后端确认统计标明修订和更新时间。本机临时统计可包含离线操作，此差异必须可见。不能把本地汇总加到云端汇总。时间未知的记录单独分组；跨午夜睡眠只分配当天重叠时段。APK 与网页比对须采用相同修订、时区、范围与缺失值口径。

### 语音输入与记录预览

| 状态 | 显示信息 | 可用操作 |
| --- | --- | --- |
| 准备 | 麦克风用途；点击开始 | 开始、打字、关闭 |
| 请求权限 | Android 原生授权 | 系统允许/拒绝 |
| 已拒绝 | 录音不可用，仍能打字 | 打字；永久拒绝时进系统设置 |
| 识别服务不可用 | 当前手机/服务暂时不能识别 | 打字、可用后重试 |
| 录音中 | 明确麦克风状态与已录时长；由用户停止 | 停止并识别、取消 |
| 识别中 | 进度与原功能归属 | 取消；不再捕获 |
| 已识别 | 可编辑文字，明确尚未发送/保存 | 输入法修正、重录、填入文字、取消 |
| 被中断 | 后台、切页或来电使捕获停止 | 有文字就用草稿，否则重录/打字 |
| 失败 | 具体权限/网络/识别原因 | 重试或打字，保留已有草稿 |

当前输入页面拥有捕获生命周期。开始先暂停播放，检查服务和权限。关闭、后台及来电释放麦克风/识别器资源。已有识别文字可以保留；没有实际保留原音频时不能声称录音已恢复。取消不会发送、创建照护记录或启动 AI。返回页面不会自动重新录音或恢复播放。

“填入文字”只把文本放回所属问答/故事输入框，不发送。语音记录显示结构化事件/时间/数量，再确认保存。未知或含糊指令保留成文字供纠正。AI 正文不会直接改记录、删数据或作医疗决定。

### 语音问答与讲故事

两者分别拥有草稿、会话/请求身份、后端任务身份、状态、结果和音频归属，不能共用一个可变“最后回复”。联网前持久保存身份。取消使请求归属失效。迟到的问答只能更新自己的问答记录，不能填入故事输入框或播放器；故事同理。进程回收后持久标记被中断，按真实后端能力提供明确重试/继续。

问答提供原生文字输入和大语音入口。建议短句只填入输入框。发送显示最终文字、使用的照护范围/上下文、处理中和取消。失败保留问题，提供重试与修改；重试按契约保留幂等任务身份。空文本不发送。新尝试失败时仍可查看前一次成功回答。

故事只在服务支持时展示时长和语气。可播放音频准备前先读文字；朗读可独立失败，保留正文并提供重试音频。用户主动点朗读后才播放。新故事取消旧生成/播放归属并创建新身份。保存故事意味着持久保存文字和媒体元数据，不能只用提示声称已完成保存。

加载、失败、取消和中断属于各自请求。后台完成可用“回答/故事已准备好”短提示回到正确结果。后端处于 DRAFT 或功能不可用时，不能展示成已经能线上调用的服务。本地演示/替代内容如存在必须明确标识。

### 音频库与播放器

分类来自后端能力。各有效分类独立呈现，一类失败不让整个目录消失。清楚显示搜索、分页条目、时长、离线可用和下载进度。本地导入及离线环境音使用同一播放器。导入上限 128 MiB/项，流式处理，播放缓存上限 256 MiB。手动下载与可清理的流式缓存分别说明。清缓存保留照护记录、文字、收藏及仍有效的引用。

一个播放器拥有一个条目。暂停保留进度，继续从当前位置恢复，停止释放资源，切歌清理旧条目后再切换。跨页播放条显示标题、状态、进度、暂停/继续和停止。完整播放器增加跳转、队列/音频库切换和可选定时停止。无障碍标签清楚区分暂停、继续、停止、前进/后退十五秒。

实现使用原生音频焦点、媒体会话与对应前台播放服务/通知。来电、耳机拔出和其他音频占用进入可见暂停状态。录音先暂停播放器；进程回收后不自动播放。通知权限/媒体服务失败可见，不承诺永久后台。设计/导出播放状态不证明音质，真机需检查音量、清晰度、断流、跳转和中断。

### 交接、提醒、导出与设置

交接按最近喂奶、活动/最近睡眠、尿布分组，各自有真实时间和状态。家长留言持久保存，可用系统输入法及已支持的语音。缺少信息显示“暂无记录”，不推断没发生。区分本机与云端新鲜度。朗读共用播放器；分享先预览再打开 Android 分享菜单，由用户选接收者。

提醒持久保存标题、到期时间、时区和完成状态。管理表单提供完成、十分钟后再提醒、编辑、删除。通知权限与调度可靠性明确。拒绝通知不删除提醒，也不声称通知一定会发。重启后重建调度，不自动生成推荐喂养或医疗计划。

第一版必须支持 CSV，流式写入用户选择的文档或分享目标。设计也展示可选 JSON；未实现时省略/禁用。选择日期和本机全部/仅云端确认范围。预览格式、条数、时区、待同步数。保留同步元数据，不含凭据和无关成人数据。大历史导出不能拼成无界内存字符串。

设置分宝宝资料、家庭服务连接、同步队列、导出、夜间/大字、通知、麦克风、下载/缓存。默认本地档案无需注册流程。有需要时一次填写家庭 URL/访问凭据，凭据遮蔽，显示真实连接/能力结果。不填虚构凭据或假定链接可用。可选设备设置不暗示已实现 BLE/NFC。若包含清空/重置，删除前解释同步代次与旧离线操作影响。

## 组件与视觉规格

| 组件 | 尺寸/留白 | 行为 |
| --- | --- | --- |
| 页面 | 水平 20 dp，区段 24 dp | 尊重系统安全区，内容可滚动 |
| 主操作 | 高度至少 50 dp，圆角 16 dp | 每个上下文一个重点；禁用/加载标签明确 |
| 点击区 | 至少 48 × 48 dp | 小图标仍有大点击区域 |
| 分组列表 | 圆角 20 dp，行上下 12 dp | 轻分隔，不嵌套卡片 |
| 列表行 | 至少 70 dp，高度自适应 | 类型/详情/状态换行，不截断关键意义 |
| 底部导航 | 至少 64 dp + 系统底部安全区 | 四个稳定标签与选中状态 |
| 迷你播放条 | 至少 64 dp，导航上方 | 内容区增加相应底部空间 |
| 底部表单 | 顶部圆角 26 dp，尊重键盘空间 | 可滚动，关闭/取消可达，返回先关闭 |
| 输入框 | 至少 48 dp，圆角 13 dp | 系统输入法/日期/时间，字段旁显示错误 |
| 字号 | 标题 24 sp、区段 16 sp、正文 16 sp、行/按钮 14 sp、辅助 12 sp | 系统无衬线/CJK 回退，全部采用 sp |
| 动效 | 转场 180 ms、状态 120 ms、撤销七秒 | 尊重减少动画，不依赖动画表达关键状态 |

日间：底色 `#FAF8F3`、白面 `#FFFFFF`、主色 `#214E43`、正文 `#233B33`、辅助 `#667267`、分隔 `#E7E9E1`、杏桃 `#F4D9C8`、浅绿 `#E8EEE4`、淡紫 `#E8E6F1`。夜间与完整角色见 token 文件。主色/底色对比 8.85:1、正文/底色 11.34:1、辅助/底色 4.75:1；夜间主色/底色 9.69:1、辅助/表面 6.29:1。以上是 token 组合计算值，实际状态组合另需检查。

夜间用深绿底和柔绿主操作，保留可读文字，不为降低亮度而损坏对比。大字尊重系统缩放，原型另提供 130% 演示。大字时快捷入口与统计列转为纵向，标签换行、表单滚动、按钮增高，不固定单行像素高度。真实应用还需检查 200% 系统字号、TalkBack、键盘焦点、对比与 Android 全屏安全区。

原型图标为 Lucide 0.468.0，在 vendor（本地产物：`vendor/`） 本地打包，附 [ISC 许可证](vendor/LUCIDE-LICENSE.txt)。原生矢量可使用风格一致的等价图标。核心操作不用 emoji。提供内容描述、选中/勾选状态，不能只靠颜色表达待同步、失败或选择。

## 关键文案与实现边界

以下保留中文产品文案和英文对应；[英文规格](design-spec.md)仅展示英文对应文案。

| 含义 | 中文产品文案 | 英文对应 |
| --- | --- | --- |
| 持久保存 | 已保存到手机 · 等待同步 | Saved on phone · Pending sync |
| 离线 | 当前离线，记录仍可保存 | Offline · Records still save |
| 空状态 | 还没有记录，从今天开始 | No records yet · Start today |
| 睡眠中 | 宝宝正在睡觉 · 计时持续中 | Baby is sleeping · Timer continues |
| 录音 | 正在听你说 | Listening |
| 识别文字 | 识别文字 · 可以修改 · 尚未发送 | Transcript · Editable · Not sent |
| 权限 | 麦克风未开启，仍可打字 | Microphone unavailable · Typing still works |
| 中断 | 录音已停止，请确认草稿或重新录音 | Recording stopped · Review draft or record again |
| AI 失败 | 这次请求没有完成，原问题已保留 | Request did not complete · Prompt retained |
| 冲突 | 另一端修改过，请选择要保留的版本 | Changed elsewhere · Choose a version |
| 清缓存 | 只清理播放缓存，保留记录与收藏 | Clear playback cache · Keep records and favorites |

原型展示预期控件和状态。系统设置/分享、真实 ASR、AI、导入、通知、音频及导出是 Android 实现责任。部分二级演示按钮用明确的交接提示替代 OS 操作。交付须分开报告 Build、Host tests、Device tests、Unverified；浏览器视觉/交互检查不证明手机麦克风、后台播放或后端可用。
