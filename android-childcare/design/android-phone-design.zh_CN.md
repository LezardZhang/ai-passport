# Android 手机版模块与语音设计

2026-10-03，第三版：自然的手机记录/问答/播放，已授权默认配置、自主 AI 档案，没有硬件管理。最新指令保留家庭中的 AI 服务。本文取代旧时长/配置建议，描述下一步实现，不代表当前 APK 已通过验收。

只读证据：原生照护（本地产物：`../reports/final-v2/care.png`）、服务配置（本地产物：`../reports/final-v2/provider.png`）、更新（本地产物：`../reports/final-v2/updates.png`），及 `MainActivity`/`FamilyUi`/`UpdatesUi`。未读取密钥值。当前单服务编辑器缺少要求的档案/模型自由；截图不能证明录音到发送行为。

## 保留三个主入口

| 入口 | 必要目的 | 重整方式 |
| --- | --- | --- |
| 照护 | 记录、问、听和行动 | 统一拥有状态的语音/文字输入；意图/结果卡；活动睡眠；紧凑播放条。手动记录、声音选择、提醒、交接为任务的次级界面。 |
| 记录 | 查阅和修正事实 | 本机日期/时间线/合计、详情编辑、撤销、导出。删除手工“核对同修订云端统计”操作，由后台对账配合准确状态。 |
| 家庭 | 管理人物及有用偏好 | 宝宝/照护者、当前记录人、夜间/系统大字偏好、数据导出、AI 服务、关于/版本。AI 服务用于主动管理档案/模型，日常照护不强制配置。 |

其余任务为次级界面：优先喂养/睡眠/尿布，其他含洗澡/趴玩，计时归事件，交接用系统分享，声音选择只显示真实可用项目。不加模型/故事/录音/设备/配网主入口。

## 逐个明确现有模块的手机用途

| 当前模块 | 决定与责任 |
| --- | --- |
| `MainActivity`、`Ui` | 保留三个主入口的原生外壳；输入状态独立于重新创建的 View，由一个输入所有者绑定文字、麦克风、状态、取消、发送。 |
| `VoiceInput`、`MicrophoneCapture` | 保留原生捕获/识别适配；生命周期、待发送和恢复归输入组件。删除固定 60 秒产品限制。 |
| `IntentRouter`、`CareRules` | 保留可测试路由/校验；含糊输入问一个明确问题，写入必须预览真实目标/时间/数量。 |
| `AiEngine`、`MimoClient`、`RequestOwner` | 保留按实际能力处理识别/模型任务、独立问答/故事/媒体归属；内部解析已授权默认配置并尊重自主档案/模型选择，保持请求配置归属不变。 |
| `Store`、`CareApp` | 保留持久记录/档案/队列/草稿和有界工作线程；持久睡眠与任务归属，事务成功才算保存成功。 |
| `FamilyUi`、`FamilyRules` | 保留本机登记/编辑/切换/停用/恢复及历史身份；日期选择、可选生日、简单关系选项，失败保留可编辑表单。AI 服务作为独立有意的次级页面打开，不把其编辑器混进人物列表。 |
| `PlaybackService`、`PlaybackRules`、`DiskMedia` | 保留真实单播放器、音频焦点、有界文件、离线声音，使用系统媒体会话/通知；暂停/继续/停止按实际状态处理。 |
| `Reminders`、`ReminderReceiver` | 保留持久提醒列表和系统调度；需要时请求通知权限，拒绝后保留提醒并解释通知限制。 |
| `Api`、`SyncService` | 仅为实际可选育儿后端保留；可用时自动对账/调度，显示本机已存/待同步/冲突及冲突恢复。不做 Wi-Fi 凭据、配网向导或常驻前台轮询要求。 |
| `UpdatesUi`、`Updates`、`UpdateRules`、`UpdateProvider` | 保留验证过的维护，归关于/版本→更新。有发布频道时用内置频道，否则系统选择签名 APK。日常移除手工频道地址、哈希、签名术语；内部校验保留。 |

删除存在的硬件配网/设备管理及无用权限；检查的手机模块不需要这些用途。

## 家庭中有意保留 AI 服务

家庭→AI 服务管理命名档案（稳定 ID、base URL、遮蔽密钥）及独立 Chat/ASR 档案/模型绑定。内置已授权 Token Plan 密钥与匹配专用地址，不配无关普通 API 地址。升级保留档案，替换/删除修复受影响绑定。

发现请求所选档案 `/models`，显示加载、ID、空态或失败，始终允许手填模型 ID。Chat/ASR 可选不同服务，各自未验证/可用/失败以实际调用为准；模型列表不证明 ASR 支持。明确测试操作失败保留编辑草稿。

未修改密钥字段保留原值，主动替换仍遮蔽，不回显。待处理任务冻结档案版本/模型，修改用于新任务。安装的系统识别可明确降级，打字始终可用；选择/修复朗读声音时才链接系统 TTS 设置。

## 一个输入组件负责录音到发送

麦克风异步填文字，`routeCare()` 却在协调捕获前拒绝空 View。发送应读取所属状态/草稿，不读取瞬时文字框。

| 状态 | 可见操作 | 发送行为 |
| --- | --- | --- |
| 空闲 | 打字或说话 | 只有这里校验真实文字草稿；无字时提示打字或说话。 |
| 录音中 | 已录时长、停止录音、取消、结束并发送 | 记录一次待发送意图，完成捕获并开始转写，不做空文字校验。 |
| 转写中 | 正在识别、取消、识别后发送 | 保留同一待发送意图，重按不能重复排队或重新识别。 |
| 就绪 | 可编辑识别文字、重新说话、发送 | 对组装后的非空草稿只路由一次；仅停止而未发送时，等待用户检查并发送。 |
| 发送中 | 真实任务进度、支持时可取消 | 重按无副作用，结果只更新所属任务；照护写入仍需结构化保存确认。 |
| 失败/中断 | 明确原因、重试、继续录音或打字 | 保留文字和有效录音材料；重试识别不重新录音或悄悄新增请求。 |

会话拥有 ID、草稿版本、目标/记录人、取消代次。识别追加但不覆盖编辑。待发送只授权路由一次，不授权未预览写入。取消使待发送/迟到回调失效；后台释放麦克风并保留有效材料，恢复不自动录音/发送。空识别用明确重试/打字错误。

不设置固定 60 秒停止。流式写入有界磁盘片段，保持顺序，在真实载荷限制内使用受支持的分段识别，不缓存整段录音。实际设备/空间/服务失败保留可用材料并准确解释恢复；消耗/丢弃后才删恢复文件，删除旧时长文案。

## 使用 Android 系统能力

| 需求 | 手机行为 |
| --- | --- |
| 网络 | 使用手机已有连接；相关时显示离线/重试，仅用户需要时打开系统网络设置。不收 Wi-Fi 密码，不给硬件配网。 |
| 麦克风与通知 | 使用时请求系统权限，界面内解释拒绝，保留打字/本机列表，必要时链接系统应用设置。 |
| 文字、日期、时区 | 系统输入法和日期/时间选择，生日未知就留空。内部保留现有统计时区并解释日界变化，人物表单不输入原始时区标识。 |
| 文件/导出/更新 | 系统文件选择/保存和分享，限定文件访问、进度/取消、草稿保留；导出不要求云账号。 |
| 音频 | 系统音频焦点/媒体会话、通知/锁屏控制；录音与播放协调，恢复后不自动重新发声。 |
| 凭据/服务状态 | 内置已授权 Token Plan 密钥及匹配专用地址；AI 服务支持命名地址/密钥档案及独立 Chat/ASR 绑定。按真实结果显示可用/离线/暂不可用；存有密钥或拿到模型列表不等于能力可用。 |
| 更新 | 显示安装版本、更新内容、进度；频道未部署时提供本机签名包更新，不假检查或让用户编辑频道。最后由 Android 系统确认安装。 |

默认档案免强制设置，AI 服务保留自主选择；有配置不证明能力，证据/日志/导出不露出密钥，不引入云注册/邀请或硬件管理契约。

## 必要验收

1. 文字框空白时在录音中发送，结束捕获、等待识别、只路由一次；保存前出现记录预览。
2. 转写中多次发送只产生一个所属任务；仅停止得到可编辑就绪文字；未识别到说话有专门可恢复错误。
3. 超过两分钟没有 60 秒自动截断，内存/存储有界，真实载荷限制被准确处理。
4. 权限拒绝、网络/空间错误、取消、Home、重建、迟到回调保留正确草稿，不能发送已取消或另一会话的输入。
5. 转写期间的文字编辑保留；切换照护者/页面不能重新归属已有任务或记录。
6. 键盘弹出、200% 字号、播放中仍能操作麦克风/发送/取消/导航并滚动对话，检查 TalkBack 标签和状态播报。
7. 全新 APK 内置已授权且匹配的 Token Plan 默认档案，无需强制设置；仍可自主管理 AI 档案，不做 Wi-Fi/频道管理。ASR 不支持/线上不可用/升级未部署如实显示。
8. 本机登记/更新/停用/恢复、撤销/导出、通知拒绝、媒体焦点及签名包升级保留现有功能检查。
9. 多 AI 档案保留遮蔽密钥，发现成功/空态/失败和手填模型 ID 可用；Chat/ASR 独立绑定，档案更改/取消不能重定向待处理请求。
