# 手机 v7：日常照护框架

设计规格，2026-10-03。本版替代[第 3 版](android-phone-design.zh_CN.md)、[简化设计](simplified-design.zh_CN.md)和历史[原生评审](native-ui-review.zh_CN.md)中的导航、视觉层级、设置归属与导出建议。本文规定实现目标，不代表 APK 已通过验收。保留已有语音会话归属与记录确认行为。

## 架构

产品仅服务一个私人家庭、一个宝宝。不增加宝宝选择器、家庭选择器、多宝宝初始化或切换宝宝档案流程。照护者切换只改变记录归属。

保留三个底部入口：照护、记录、家庭。每个根页面的标题栏提供 48 dp 设置齿轮触区，打开独立设置页面。家庭仅包含宝宝与照护者。设置使用返回标题栏，不选中“家庭”。二级页面使用真正的父级返回栈：音频详情返回音频库，音频库返回首页原位置。切换底部入口恢复各自位置；设置子页返回设置。不要让所有返回操作都直接回首页。

| 页面 | 内容与直接操作 |
| --- | --- |
| 照护 | 今日事实、进行中睡眠、快捷记录、近期提醒、声音与故事、最新回复预览和最近记录 |
| 记录 | 日期选择、当日汇总、时间线、新增/补记、详情/编辑/删除/撤销；交接摘要入口 |
| 家庭 | 紧凑的宝宝身份/生日/月龄、资料编辑、当前照护者和人员列表；人物详情承载切换/编辑/停用/恢复 |
| 设置 | AI 服务、同步、备份与导出、通知、版本与更新；紧凑分组列表 |
| 音频库 | 分类、真实可用音频、本地/云端可用状态、播放、导入；完整播放器承载实际支持的进度/定时 |
| 照护提醒 | 待办/逾期提醒、新增、详情、完成；只在相关时显示通知状态 |
| 对话 | 有独立归属的请求历史与完整回复；从首页最新回复进入；也提供输入栏 |
| 照护交接 | 最近照护摘要、可编辑备注、保存与系统分享；从记录页标题栏进入 |

AI 配置不成为底部入口。不提供硬件/配网页面、夜间模式开关、用户填写的时区字段、备份地址编辑或备份凭据编辑。

## 首页组成

采用安静的暖色背景、统一纵向阅读顺序与分组行。普通字号下，360 dp 宽内容视口应无需长距离滚动即可看到提醒和音频分区标题。大字号允许滚动，不为达到此目标缩小控件或截断事实。

1. **标题栏，56 dp：** 左侧宝宝姓名/月龄（姓名 20 sp，下方日期 12 sp），右侧设置。月龄未知就不显示。没有标语、大头像或独立登记卡片。
2. **进行中睡眠，仅有数据时显示，约 72 dp：** 月亮图标、已睡时长、开始时间、右侧结束操作。深绿背景突出进行中状态，不使用 44 sp 巨型计时器。时长由持久化开始时间计算。
3. **今天，约 64 dp：** 同一个容器内展示喂养总量/次数、已完成睡眠、尿布次数。数字 22 sp，标签 12 sp。未知奶量保持未知；进行中睡眠不悄悄算入已完成睡眠。只在有用时下方显示 12 sp 本地/待同步状态。
4. **快捷记录，48–56 dp：** 喂养、睡眠、尿布、更多；等宽短标签与图标。更多仅包含其他记录类型，不隐藏提醒、音频或设置。大字号时两列换行。
5. **照护提醒：** 18 sp 分区标题与右侧“全部”，标题行最小 40 dp。最多显示两个近期/逾期提醒，每行 56–64 dp，包含时间、任务与完成操作。空状态为一行“添加提醒”，不放装饰空卡或每次启动重复的权限警告。
6. **声音与故事：** 同规格标题及“音频库”入口；白噪音、摇篮曲、故事分类触区 48 dp；一至两个真实可播放条目，每行 56 dp。仅在确有本地雨声时提供，不伪造封面或目录。云端失败保留本地条目与一行重试。
7. **最新回复：** 仅有请求时显示；问题/状态、最多三行回复、“打开对话”。处理中/失败任务在此可恢复。长回答与五个重复对话卡片不得把日常照护内容挤出屏幕。
8. **最近照护：** 最近三条的时间、类型、数量/详情、照护者；“全部记录”入口。没有数据就用真实简短空状态。

资料缺失使用相关区域附近一行 44–48 dp 可关闭提示，不做主导首页的大面板。更新通过设置齿轮圆点和设置列表徽标提示。有紧急处理意义的同步冲突用紧凑状态行进入详情；日常正常同步不占卡片。

### 360 × 800 dp 视口预算

以状态栏 24 dp、手势区 24 dp 为示例，可用应用高度为 752 dp。扣除 56 dp 标题栏、64 dp 空闲输入栏和 56 dp 底部导航后，**可见滚动内容为 576 dp**。实际 inset 必须测量，不可硬编码。正在播放时再扣 56 dp，剩 520 dp。按以下顺序安排紧凑首页：

| 内容 | 包含相邻间距的高度 |
| --- | --- |
| 进行中睡眠，有数据时 | 72 + 8 = 80 dp |
| 今日汇总 | 64 + 8 = 72 dp |
| 快捷记录 | 48 + 12 = 60 dp |
| 提醒标题与第一条提醒 | 40 + 56 + 12 = 108 dp |
| 音频标题、分类与第一条可播放音频 | 40 + 48 + 56 = 144 dp |
| 有进行中睡眠时合计 | **464 dp** |

因此，即使同时有进行中睡眠与播放器，首条真实提醒和首条真实音频也可放入 520 dp。360 × 800 dp 手机默认紧凑预览数量为**一条提醒、一条音频**，“全部/音频库”进入完整列表。仅当实测剩余高度允许时展示第二条，不得让第二条提醒挤掉第一条音频。必要状态行增加 20 dp 时合计 484 dp，播放器场景额外内容上下内边距须控制在剩余 36 dp 内。最新回复与最近照护继续放在首屏下方。无进行中睡眠时，多出的 80 dp 可展示另一行。200% 字号或键盘展开时，这些高度是最小值而非截断框，滚动优先于首屏展示目标。

## 底部区域与语音

使用原生纵向骨架：固定标题栏、占剩余空间的滚动内容、可选播放条、上下文输入栏、底部导航，系统 inset 仅应用一次。照护与对话提供输入栏；记录、家庭、设置不提供。空闲输入栏为单行 56–64 dp：48 dp 麦克风触区、弹性文字输入、48 dp 发送触区。使用简短提示，不允许三行提示语、永久说明、两个整宽按钮及隐藏控件残留边距。空文本时发送禁用并提供无障碍说明。输入最多增长到三行，再内部滚动。

录音或识别时可增加一行紧凑状态及取消操作；仅存在有效音频时错误状态才显示重试。未使用的状态/操作容器整体设为 `GONE`。录音期间即使没有文字也必须可发送：停止录音、等待识别、只路由一次。仅停止录音则保留可编辑转写。保留 `SpeechSession` 归属、取消代次及重复发送保护。草稿恢复不自动发送。权限拒绝保留文字并给出明确恢复操作。进入后台按已验证策略清理录音；没有保留材料时不得宣称原始音频可恢复。

键盘打开时以 `ADJUST_RESIZE` 保证输入栏位于 IME 上方；隐藏底部导航，把空间还给内容。返回首先收起键盘。200% 字号允许更高输入框和独立紧凑状态行，麦克风/发送/取消保持 48 dp 触区，不堆叠大操作面板。极短视口无法容纳有效内容时，可把聚焦输入展开成独立输入面板。

音频播放时增加一行 52–56 dp 播放条：标题、暂停/继续、停止，每个操作至少 48 dp。空闲不显示。音频库/完整播放器已有控制时不重复显示全局播放条。录音协调音频焦点，返回页面不自动重新播放。不可用、缓冲、暂停、停止、失败必须是不同状态。

## 视觉系统

| 令牌 | 数值与用途 |
| --- | --- |
| 画布 | `#F7F5EF`，温暖中性背景 |
| 容器 | `#FFFFFF`，共享分组容器，不是每句话一张卡 |
| 主文字 | `#233B32` |
| 次文字 | `#667267`；实现渲染后验证对比度 |
| 主色 | `#285747`，重要操作与选中导航 |
| 浅绿 | `#E9F0E9`，安静的选中分类及辅助状态 |
| 桃色 | `#F4DDCB`，偶尔的类别强调，不隔一张卡就用 |
| 分隔线 | `#E6E9DF`，1 dp 分组分隔 |
| 错误 | `#9D3027`，同时提供文字/图标，不只靠颜色 |
| 字体 | 系统无衬线；标题 22 sp、分区 18 sp、正文/操作 16 sp、元信息 12–13 sp；中等字重只用于层级 |
| 间距 | 外边距 16 dp，分组内边距 12 dp，行间 8 dp，分区间 20 dp；圆角 12–16 dp |
| 图标 | 统一 22–24 dp 描边矢量/Canvas 路径，48 dp 触区；导航不使用 emoji |

不需要照片素材。宝宝身份旁可用小叶片/种子矢量，但不得增加高度。避免阴影、渐变、巨大胶囊和嵌套圆角卡。原生 `LinearLayout`、`ScrollView`、`TextView`、`EditText`、`GradientDrawable`、`RippleDrawable` 与小型图标 View 足够。设置按钮语义、可点击/聚焦、有效描述与选中状态。分组行优于重复调用现有 20 dp 内边距、24 dp 圆角的 `Ui.card()`。

## 家庭与云端身份

成功读取资料后，宝宝行显示云端权威生日及推导月龄，沿用原有宝宝 ID。启动先显示本地缓存，再通过内置的 `162.14.108.234` 自有服务自动同步服务器已有宝宝资料与家庭照护数据。这是默认行为，不是可选连接向导；沿用唯一的宝宝身份与家庭上下文。具体传输、路径和认证由应用配置决定；IP 本身不等于凭空定义的 API 合同。读取失败保留缓存生日，仅在资料详情标记过期/离线。生日缺失保持未设置。不得因旧本地登记标记为 false 而强制重复登记。确实缺失的资料可编辑，不能另建重复身份破坏既有记录归属。

照护者登记只有“我是孩子的 ___”一句话和一个自由填写的称谓，如爸爸、爷爷、奶奶，不再要求姓名或联系电话。名单显示称谓、当前徽标或箭头，新记录携带相同称谓同步到云端，已有记录保留历史快照。点击进入详情，不为每人摆三个整宽按钮。切换当前照护者只影响未来记录；停用保留历史身份。服务器不支持同步的照护者资料在相关位置明确标记本地。此处没有外观、AI、备份、更新、时区字段。

## 设置与独立能力

设置为 56–64 dp 分组行，附简短当前状态。AI 服务首页展示五类：文字推理、语音识别 ASR、语音合成 TTS、视觉、JEV 判断（`judge`）。每类显示独立选中的服务/模型与健康状态，不在总览展开巨大编辑器。

每类详情拥有服务名称、端点、掩码 Key、模型 ID 与实际支持的适配器/协议。支持命名配置、手填模型以及从所选服务获取模型。选择或编辑一类不得覆盖其他类的端点/Key/模型；复用其他配置必须显式操作。保存只代表保存配置；测试反映真实能力，不可用文字成功推导 ASR/TTS/视觉成功。模型列表不是能力测试。错误保留草稿，配置版本变化后丢弃过期测试/列表结果。进行中请求保持不可变配置快照。

用户已澄清原 GEV 标签指 JEV 判断模型：独立 `judge` 角色负责判断/路由，具有自己的端点、Key 与模型。未选择判断模型时保留经过测试的确定性意图规则。已配置判断模型只能通过实际实现的兼容适配器调用；保存字段不代表适配器或能力已可用。模型分类仍须输出经验证的类型化意图，对歧义进行澄清，并保留照护写入的显式确认。不得由此标签发明视频或 Gemini 能力。TTS 可将 Android 系统朗读作为明确选中的备选，设置与可用性独立于远端 TTS。真实图片输入流程出现前可以配置视觉，但明确说明限制，不提供假装可用的相机操作。

同步固定连接自有后端，正常自动工作，展示上次成功、待同步数、手动重试与冲突详情。错误说明可重试内容并保留本地记录。包括首次启动在内移除地址/Key 设置表单。服务身份/代次检查仍作为内部正确性控制。不得仅因预置配置存在就显示已连接。

备份与导出提供“导出备份（.zip）”或实际支持的 `.bak` 容器，使用 Android 文件保存器。输出真实归档，包含清单/架构/应用版本/时间、一致的记录/资料/提醒快照及恢复所需元信息，明确列出媒体清单/排除项。CSV 可作为归档内部成员，不得把唯一 CSV 改名为 `.zip`/`.bak`。包含完整性校验，排除密钥。展示准备中、写入中、完成（文件名/大小）或失败；失败不宣称已有可用备份。没有验证、预览和事务恢复时不提供假装可用的恢复操作。仅支持导出时应明确恢复暂未开放。

版本与更新默认使用独立 `/android-updates/` 清单和 APK 服务。迁移期间会回退到旧 `/cloud-backup/android-childcare-updates/` 清单/下载路径，并记录成功来源；两者都保留同签名、哈希和安装校验。界面显示当前版本、上次检查、更新说明、进度与校验后的安装操作，由系统安装器确认。哈希/签名/通道地址留在诊断中。检查失败保留带日期的旧信息；没有通道不等于已是最新版。

## 实现与验收

`MainActivity` 管理路由/父级状态与根骨架；`Ui` 增加紧凑标题栏/分组行/分类/图标操作组件；`CareComposer` 改表现而保留状态机；`FamilyUi` 只负责人物；`AiSettings` 按能力组织详情；`UpdatesUi` 使用紧凑列表。不要在每次观察通知/计时刷新时重建正在输入的 EditText 或录音会话。后台刷新保留焦点、选区、草稿与滚动位置。状态归属于对应操作/请求 ID。

视觉检查：360 dp 与 411 dp 宽，空/有数据首页，进行中睡眠，逾期提醒，本地音频/云端失败，播放器与输入栏共存，键盘展开，200% 字号，全部设置类别与家庭列表。确保固定栏不遮挡滚动内容，操作不落入系统手势区。行为检查：根页/返回历史；录音发送恰好一次；停止/取消/迟到结果；五类独立配置；云端生日无需重复登记；同步失败保留数据；真实归档内容/完整性；更新失败与重试。截图必须来自原生应用，原型证据不能认证 Android 行为。
